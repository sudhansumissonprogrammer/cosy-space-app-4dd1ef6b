## 2. Pincode Delivery Date app — P0 fetch-order fix

**Problem:** `PincodeDeliveryChecker` called `api.postalpincode.in` from the browser first. That endpoint has strict CORS + rate-limits and often 502s, so every shopper ate one failed fetch before the fallback fired.

**Fix:** swap the fetch order — call our own edge proxy `pincode-lookup` first (edge-cached 24h, owned infra, correct CORS), fall back to the public API only if the proxy is unreachable.

### Files modified
- `src/components/storefront/PincodeDeliveryChecker.tsx` — inside the `lookupPincode()` helper, `tryProxy()` now runs before `tryPublic()`. No other logic changes.

### Backend
- Uses the existing `pincode-lookup` edge function (already deployed on main). No new function or migration.

## 3. Migrate My Store — 3 hardening fixes

**Problems solved**
1. Third-party access tokens (Shopify admin token, Woo consumer key/secret) sat in `migration_jobs.credentials` forever after the job finished.
2. Fire-and-forget worker chain could silently die on cold-start / isolate recycle, leaving jobs stuck in `running` forever.
3. Malformed `source_url` (e.g. `"mystore"`) got persisted and the worker failed every page with no useful signal.

### Files modified
- `supabase/functions/migration-worker/index.ts` — when the job reaches a terminal state (`completed` or `failed`), the `.update()` also clears `credentials: {}`.
- `supabase/functions/migration-status/index.ts` — if a job is still `running` with no `completed_at` and `started_at` (or `created_at` fallback) is >5 minutes old, fire a fire-and-forget re-kick of `migration-worker` with the job id. Returns `resumed: true` so the client can surface it. Worker is idempotent (product upserts use `onConflict: "store_id,source_platform,source_id"`), so re-kicking a healthy worker is safe.
- `supabase/functions/migration-start/index.ts` — before insert, normalize source_url (add `https://` if missing), then `new URL(...)` — reject if it fails to parse or has no dotted hostname.

### Backend
- No new tables, no new function, no new secrets. Just edits to the three existing edge functions above.
