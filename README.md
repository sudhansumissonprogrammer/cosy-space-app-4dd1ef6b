# shopbanao

Create a full-stack web application with the following stack:

Frontend:
Next.js with Tailwind CSS

Backend:
Node.js API

Database:
PostgreSQL

Requirements:

Authentication system with signup and login.

Dashboard layout with sidebar navigation.

Prepare database connection and ORM.

No ecommerce features yet.

Pages needed:

Login

Signup

Dashboard

The dashboard should be empty for now but ready to add modules later.

Use a clean SaaS dashboard UI similar to modern admin panels.
