JD Store Spy - install
1. Unzip this folder.
2. Open chrome://extensions
3. Turn on Developer mode (top right).
4. Click "Load unpacked" and pick the unzipped jd-store-spy folder.
5. Open any *.jdwebshop.com / *.jdwebnship.com / *.jdwebconnect.com store.
   The panel appears top-right. Click the toolbar icon to search 1,020 stores.

Note: JD stores do not publish order counts. "Top" is an estimate from
days live, featured placement, discount, photos/video and position.
