JD Store Spy - install
1. Unzip this folder.
2. Open chrome://extensions
3. Turn on Developer mode (top right).
4. Click "Load unpacked" and pick the unzipped jd-store-spy folder.
5. Click the toolbar icon to search the bundled store directory.

API-backed scanning is disabled: private credentials must not be bundled in a
browser extension. No replacement private key should be entered into its files.
Previously bundled keys must be revoked/rotated with their issuing provider.
Removing a key from current files does not remove it from GitHub history or
previously downloaded copies. Reload this extension to replace installed code.

Note: JD stores do not publish order counts. "Top" is an estimate from
days live, featured placement, discount, photos/video and position.
