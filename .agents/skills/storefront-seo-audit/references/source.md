## Adaptation

Retain the upstream crawlability-first audit, ecommerce checks, performance review, schema inspection caution and evidence/priority reporting. Replace runtime-specific tools with the project's available findings, browser, source and edge checks. Add tenant boundaries, factual product/schema rules, app/edge/Worker parity, bounded traffic, deployment distinctions and preservation requirements.

Exclude the upstream AI-writing detection rules, blanket local-business expansion, fixed title/description limits, categorical multilingual ranking claims and automatic mass content/page creation. This skill has no executable scripts, tracking integrations, API keys or shopper runtime dependencies. Consult current primary search-engine/vendor documentation for changing behavior rather than treating this snapshot as authoritative.

Activation makes the workflow available to future audit requests. It does not audit every store automatically, continuously monitor production, connect Search Console, deploy Worker changes, or guarantee search outcomes.
